## Status values

- `current`: currently applicable
- `superseded`: retained for historical interpretation
- `retired`: no longer applicable and has no direct replacement
- `unknown`: applicability has not been verified

## Extraction values

- `none`: original only
- `text`: searchable text layer extracted
- `ocr`: scanned pages OCRed; source-page verification required
- `structured`: tables/images normalized with source references
